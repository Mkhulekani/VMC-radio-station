# VMC Planet Radio website

Run it:

    npm install
    npm run dev

Pages (all inside this site): Home, Show line-up, On-air presenters, Competition,
Events, Merchandise, News, Careers, Podcasts, Radio drama, VMC TV, Submit music,
Gallery, Advertise, About us, Contact us.

Everything you edit lives in `src/data.js`: menu, shows, news, competitions,
events, merchandise, podcasts, radio dramas, videos, gallery, contact details.
